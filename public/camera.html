How this works

This viewer loads whatever URL is saved as the institute's CCTV stream — it does not host or record video itself. For a live phone-as-camera demo: install a free IP-camera app (e.g. "IP Webcam" on Android, or "EpocCam" / "IP Camera Lite" on iPhone), start streaming, and paste the app's given URL (usually like http://<phone-ip>:8080/video) into the institute's CCTV Stream URL field. The phone and the device viewing this page must be reachable from each other — same Wi-Fi network works out of the box; to let this live website reach a phone anywhere, tunnel the phone's stream through a service like ngrok and use the public URL it gives you instead.
